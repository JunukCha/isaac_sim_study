# Basic Tutorials

[한국어](README.ko.md) · [Back to root](../../../README.md)

Small exercises for learning Isaac Sim scene and robot APIs.

| Script | Purpose |
| --- | --- |
| `check_print.py` | Simple environment/output check |
| `hello_world.py`, `hello_world2.py` | Basic Isaac Sim API experiments |
| `box.py` | Cube creation and scene setup |
| `add_franka.py` | Adds a Franka robot asset to the stage |
| `move_robot.py` | Experiments with Franka articulation and IK |

Some scripts do not create a `SimulationApp`. Run them from **Window > Script Editor** in the Isaac Sim GUI, or from an existing Isaac Sim application context. These incremental exercises may assume that required prims already exist on the stage.
