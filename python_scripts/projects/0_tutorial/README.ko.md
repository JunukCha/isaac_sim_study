# 기초 튜토리얼

[English](README.md) · [루트로 돌아가기](../../../README.ko.md)

Isaac Sim 장면 및 로봇 API를 익히기 위한 작은 실습 모음입니다.

| 스크립트 | 내용 |
| --- | --- |
| `check_print.py` | 실행 환경 및 출력 확인 |
| `hello_world.py`, `hello_world2.py` | 기본 Isaac Sim API 실험 |
| `box.py` | 큐브 생성 및 장면 구성 |
| `add_franka.py` | 스테이지에 Franka 로봇 에셋 추가 |
| `move_robot.py` | Franka articulation 및 IK 실험 |

일부 스크립트는 `SimulationApp`을 직접 생성하지 않습니다. Isaac Sim GUI의 **Window > Script Editor** 또는 이미 실행 중인 애플리케이션 컨텍스트에서 실행하세요. 단계별 학습 코드이므로 필요한 prim이 스테이지에 이미 있다고 가정할 수 있습니다.
